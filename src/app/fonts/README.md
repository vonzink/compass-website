# Hanken Grotesk

`hanken-grotesk-latin-variable.woff2` is the Latin variable-font subset served
by Google Fonts for Hanken Grotesk. It is self-hosted so application builds do
not depend on Google Fonts availability.

The font is licensed under the SIL Open Font License 1.1. See `OFL.txt`.
The upstream family is maintained in the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/hankengrotesk).
